# paybackGIS
보상사업용 엑셀-사업지구해치-shp-api연계 웹앱

지번 기반 엑셀 연동 GIS 시스템

지번조서 엑셀(.xlsx)과 국토교통부 브이월드(VWorld) 연속지적도 API, 로컬 SHP(.zip) 및 AutoCAD 사업구간 도면(.dxf)을 웹 브라우저에서 즉시 공간 매핑·시각화·일괄 편집할 수 있는 단일 HTML 기반 GIS 도구입니다.

**주요 기능**

1. **엑셀 지번조서 연동 및 지적경계 매핑**

  스마트 헤더 탐지 & 지번 정규화: 엑셀 시트 내 지번 열 또는 분리된 법정동 + 본번 + 부번 열을 자동 인식하여 19자리 PNU 코드로 변환합니다.

  브이월드 연속지적도 대량 조회: 논블로킹 배치 큐(중지 버튼 지원)로 수천 건의 필지 경계를 안정적으로 조회합니다.

  오프라인 연속지적도 병합: 사내망 등 외부 API 차단 환경에서도 국토정보플랫폼 연속지적도 SHP(.zip) 또는 GeoJSON 파일을 직접 올려 즉시 매핑할 수 있습니다.

  브이월드 배경지도 및 지적편집도: API 키 입력 시 브이월드 일반지도(WMTS)·위성지도 및 연속지적도 오버레이(WMS)를 지원합니다.

2. **AutoCAD(.dxf) 사업구간 해치 자동 추출 및 정합**

  순수 해치(HATCH) × 문자(TEXT/MTEXT) 매칭: 레이어가 분리되지 않은 도면에서도 해치 경계 내부 또는 경계와 겹치는 CAD 문자를 자동 인식해 사업구간 명칭을 부여합니다.

  지적도 자동 맞춤 & 기준점 보정: 좌표계가 없는 로컬 CAD 도면도 조회된 지적 필지 군집 크기에 맞춰 자동 배치되며, 1점 평행이동 / 2점 기준점(위치·스케일·회전) 클릭 및 수치 미세 보정을 지원합니다.

  사업구간별 필지 필터링 및 엑셀 열 추가: 지도 위 사업구간 클릭 또는 드롭다운 필터로 구간 내 필지만 추려보고, + 엑셀 열 추가로 각 필지가 속한 사업구간명을 엑셀에 자동 기록합니다.

3. **엑셀 표 편집 및 프로젝트 상태 저장**

  다중·범위 일괄 수정: 좌측 테이블에서 Shift + 클릭 또는 Ctrl + 클릭으로 여러 행을 일괄 선택한 뒤 특정 열(또는 새 열)의 값을 일괄 덮어쓰기·추가·비우기 할 수 있습니다.

  표 레이아웃 커스터마이징: 좌측 패널 너비 드래그 조절, 열 너비 드래그 조절(더블클릭 자동 맞춤), 불필요한 열 숨기기/보이기를 지원하며 [수정본 엑셀 저장] 시 실제 .xlsx 파일의 열 너비와 숨김 속성(!cols)까지 그대로 저장됩니다.
  
  작업 프로젝트(.json) 저장/불러오기: 수정된 엑셀 데이터, CAD 사업구간 변환 상태, API 키, 이미 매핑된 지적 폴리곤을 .json 파일로 저장해 다음 작업 시 API 재호출 없이 즉시 복원할 수 있습니다.


**사용 방법**

changneung_gis_app.html 파일을 최신 웹 브라우저(Chrome, Edge 등)에서 엽니다.

상단 [브이월드 API 키]를 입력하거나 [지적도 SHP(.zip)]을 준비합니다.

[엑셀 첨부 (.xlsx)]로 지번조서를 업로드한 뒤 지번 기준 열을 선택하고 [선택한 지번 열로 브이월드 지적도 조회]를 실행합니다.

필요 시 [CAD 사업구간 (.dxf)]을 추가해 구간별 필지를 필터링·수정하고 [수정본 엑셀 저장] 또는 [작업 저장]으로 결과를 보관합니다.
