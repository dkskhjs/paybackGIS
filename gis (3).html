브이월드(VWorld) 오픈API 인증키 설정

브이월드(vworld.kr)에서 발급받은 오픈API 인증키를 입력하면 연속지적도(`LP_PA_CBND_BUBUN`) 필지 폴리곤과 배경 지적편집도를 조회할 수 있습니다.

브이월드 인증키 서비스 URL(도메인) 안내

• 로컬 PC에서 열 때: 브이월드 키 설정에 http://localhost 등록
• 현재 브라우저 감지 도메인: localhost

브이월드 연속지적도 API 호출·응답 진단

브이월드 서버가 반환한 최근 응답 원본입니다. INCORRECT_KEY / INVALID_DOMAIN이 표시되면 브이월드 인증키 설정의 서비스 URL(도메인)을 확인하시고, 네트워크 차단이 지속되면 상단 [지적도 SHP(.zip)]으로 오프라인 즉시 매칭이 가능합니다. 

아직 호출 기록이 없습니다.

CAD 도면 위치·스케일·회전 보정

1. 지도 위 기준점 클릭 정밀 맞춤

CAD 도면의 기준 모서리와 실제 지적도 위 동일 지점을 클릭하면 위치·축척·회전이 자동 계산됩니다.

2. 수치 미세 조정 (이동 · 배율 · 회전)

CAD 해치별 사업구간 명칭 편집

해치 경계 내부의 CAD 문자(`TEXT`/`MTEXT`)에서 자동 매칭된 구간명입니다. 수정 후 저장하면 지도와 엑셀 열에 즉시 반영됩니다.
